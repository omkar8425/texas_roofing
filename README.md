# Texas Edge Roofing website

This is a responsive static website that can be uploaded to nearly any web host.

## Publish it

1. Extract `texas-edge-roofing-site.zip`.
2. Upload the **contents** of the `texas-edge-roofing-site` folder to your host's public web folder (often named `public_html`, `www`, or `htdocs`).
3. Make sure `index.html`, `styles.css`, `script.js`, and the `assets` folder stay together.

## Before going live

- The inquiry form is a polished front-end form only. Connect it to an email service or CRM (Formspree, HubSpot, etc.) to receive requests.
- The copy uses the company's published phone, email, offices, service categories, and RCAT license reference. Confirm these details before publishing.
- The hero image is an original AI-generated visual created for this project; it is not an Instagram photo.
